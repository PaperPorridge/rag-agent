# IT 设备标准配置清单

## 1. 开发机

公司开发机型号为 ThinkPad-X1-Carbon-Gen12，标配内存 32GB，标配硬盘 1TB SSD。
算法岗与后端开发岗按同一标准配置，不因岗位另加内存。
需要 64GB 内存的特殊场景（大模型微调、本地向量库压测）需走 IT 工单单独审批。

## 2. 显示器

每位员工标配 27 英寸 4K 显示器一台，型号 Dell-U2723QE。
设计岗与视频剪辑岗可申请加配一台同型号显示器，需部门负责人在工单内说明。
显示器申请同样走 IT 工单，响应时间为 3 个工作日内。

## 3. 外设

- 键盘、鼠标每 2 年可申领一套，型号罗技 MX 系列
- 降噪耳机每 3 年可申领一副
- 显卡扩展坞型号为 RTX-4090-24G，申请需走 IT 工单
- 外设申领统一由 IT 工单发起，响应时间为 3 个工作日内

## 4. 折旧与换新

开发机按 4 年计提折旧，折旧期满不再强制换新。
已使用满 3 年且性能不满足业务需要的，可申请提前换新，需部门负责人审批。
换新后旧设备统一回收，员工不得自行留存或带离公司。

## 5. 借用与归还

短期借用设备（含出差借用笔记本）最长 30 天，逾期需重新提交借用单。
离职时设备须在 3 个工作日内归还 IT 部，未归还的按折旧残值从工资中扣除。
